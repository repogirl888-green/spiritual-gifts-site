## How the site works

1. **Logo reveal.** The page opens on a lavender screen. The lotus petals open, the flame lights, and the name and "Wellness & Ritual" fade in.
2. **Enter button.** Browsers don't allow sound to start by itself, so the music begins when a visitor taps Enter. "Enter without sound" skips it. A small sound button in the corner turns the music on and off.
3. **Homepage.** Hero photo, the product collection, crystals, meditations, the story, a Join the list section, and the footer.

## Publishing with GitHub Pages

1. Put `index.html` in a repository (the repo must be public for free GitHub Pages).
2. Go to **Settings, then Pages**.
3. Under "Build and deployment," choose **Deploy from a branch**, then **main** and **/ (root)**, then Save.
4. The site address appears on that page after a minute or two.

To update the site later, upload the new `index.html` (upload first, then delete the old one, then rename, one file at a time).

## Things you can change in `index.html`

Use the browser's find function (or GitHub's editor search) to locate each one.

- **Music:** near the bottom, find `MUSIC_SRC`. While it is empty, a soft generated pad plays. To use your own track, paste its `data:` address between the quotes, and it will loop.
- **Prices:** each product says `Coming soon`. Replace it with the price when you're ready.
- **"Notify me" buttons:** they open an email to spiritualgifts8888@gmail.com. When you have a checkout, change each one to the product's buy link.
- **Email address:** search for `spiritualgifts8888@gmail.com`.
- **Story:** search for `A practice I've kept for years`.
